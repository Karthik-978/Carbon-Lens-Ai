# 🌱 CarbonLensAI

CarbonLensAI is an AI-powered application that estimates the carbon footprint of food by analyzing food images and connecting the detected food with carbon-emission data.

## Features

- 📷 Food image analysis
- 🤖 AI-based food classification
- 🌱 Carbon footprint estimation
- 📊 Carbon impact information
- 🔄 Carbon data visualization

## Workflow

```text
Food Image
    ↓
AI Food Classification
    ↓
Carbon Database
    ↓
Carbon Calculation
    ↓
Carbon Impact
```

## Tech Stack

- Python
- Flask
- Computer Vision
- AI / Machine Learning
- Carbon-emission dataset

## Purpose

CarbonLensAI aims to make people more aware of the environmental impact of their food choices through AI-powered carbon footprint estimation.
